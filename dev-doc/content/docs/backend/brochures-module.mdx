# Marketing Brochures & Gallery

The `internal/brochure` package manages public downloadable marketing collateral and corporate gallery items.

---

## 🎨 Features

- **Public Gallery**: Serves active marketing assets (`GET /api/v1/brochure`).
- **Media Upload**: Supports high-resolution cover image and PDF uploads (`POST /api/v1/admin/brochure/upload`).
- **Video Linking**: Supports embedding YouTube overview links for multimedia showcases.
