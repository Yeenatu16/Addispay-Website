# Docker Architecture

The repository includes complete Docker configurations for containerized local development and production deployments.

---

## 🐳 Docker Compose Architecture (`docker-compose.yml`)

```text
┌────────────────────────────────────────────────────────────┐
│                    docker-compose.yml                      │
│                                                            │
│  ┌──────────────────┐    ┌─────────────────┐    ┌───────┐  │
│  │   addispay-fe    │───►│   addispay-be   │───►│  db   │  │
│  │   (Port 3000)    │    │   (Port 8080)   │    │(Postg)│  │
│  └──────────────────┘    └─────────────────┘    └───────┘  │
│            ▲                                               │
│            └────── Volume: /uploads/ (Persisted) ──────────┘
└────────────────────────────────────────────────────────────┘
```

---

## 🚀 Running with Docker Compose

```bash
docker compose up --build
```

- **Frontend**: Accessible at `http://localhost:3000`
- **Backend API**: Accessible at `http://localhost:8080/api/v1`
- **Database**: PostgreSQL 16 on `localhost:5432` with automatic volume persistence.
