# Admin Protected Endpoints

All endpoints below require an `Authorization: Bearer <token>` header obtained from `POST /api/v1/auth/login`.

---

## 🔒 Authentication & Sessions
- <EndpointBadge method="POST" path="/api/v1/auth/login" />: Login with email & password.
- <EndpointBadge method="POST" path="/api/v1/auth/register" />: Bootstrap initial Super Admin.
- <EndpointBadge method="POST" path="/api/v1/auth/forgot-password" />: Request password reset email.
- <EndpointBadge method="POST" path="/api/v1/auth/reset-password" />: Complete password reset with token.
- <EndpointBadge method="GET" path="/api/v1/auth/invitations?token=..." />: Resolve invitation preview.
- <EndpointBadge method="POST" path="/api/v1/auth/accept-invitation" />: Accept invite and activate account.
- <EndpointBadge method="GET" path="/api/v1/admin/me" />: Return authenticated user session profile.

---

## 📰 News Administration (`Role: SuperAdmin | Marketer`)
- <EndpointBadge method="GET" path="/api/v1/admin/news/articles" />: List all articles (including drafts).
- <EndpointBadge method="GET" path="/api/v1/admin/news/articles/:id" />: Fetch single admin article.
- <EndpointBadge method="POST" path="/api/v1/admin/news/articles" />: Create new article.
- <EndpointBadge method="PUT" path="/api/v1/admin/news/articles/:id" />: Update existing article.
- <EndpointBadge method="DELETE" path="/api/v1/admin/news/articles/:id" />: Permanently delete article.
- <EndpointBadge method="POST" path="/api/v1/admin/news/upload" />: Upload and compress cover image to WebP.
- <EndpointBadge method="GET" path="/api/v1/admin/news/settings" />: Get news settings.
- <EndpointBadge method="PUT" path="/api/v1/admin/news/settings" />: Update news settings.
- <EndpointBadge method="GET" path="/api/v1/admin/news/audit-logs" />: Get news audit trail.
- <EndpointBadge method="GET" path="/api/v1/admin/news/subscribers" />: List newsletter subscribers.
